# E-9: токены и цена запуска агента, сверка на стенде

16.11.2026, коммит `69a586a`, стенд Selectel.

## Почему раньше были нули

`RunBudget` слушал колбэк `on_chat_model_end`. У колбэков LangChain его нет: ответ чат-модели
приходит в `on_llm_end`. Поэтому токены запуска были нулём на любом маршруте, не только на LiteLLM.
Вызовы при этом считались: `on_chat_model_start` существует. Тест
`tests/test_agent_budget.py::test_openrouter_model_on_litellm_route_reaches_budget` падает на старом
имени колбэка.

## Как сверяем

Два независимых пути:

- `agent_runs.usage` — итог колбэка бюджета (`RunBudget.snapshot()`);
- `llm_usage` — журнал вызовов, его пишет клиент модели из сырого `usage` HTTP-ответа; связь с
  запуском — `llm_usage.agent_run_id` (контекст задачи запуска).

Скрипт — `reconcile.sql` (команда запуска в шапке файла). Попадания в кэш результатов модель не
вызывают и исключены.
