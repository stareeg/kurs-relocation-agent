# Тайминги узлов запусков агента (A-3, OQ-29)

Метрика p90 шага: события `node_timing` пишутся в `agent_events` при каждом запуске
агента (узлы plan / step / check / replan / finalize / confirm, миграция 0155).
Порог по OQ-29 — **p90 шага ≤ 60 с**.

## Как снять

1. Поднять стенда на актуальном коммите, сделать живой прогон агента (режим «Агент»
   в главном чате, цель на демо-данных).
2. Выполнить:

   ```bash
   uv run python probe/2026-11-16-agent-latency/p90_nodes.py            # все запуски
   uv run python probe/2026-11-16-agent-latency/p90_nodes.py --run-id N # один запуск
   ```

   Скрипт печатает n / p50 / p90 / max по узлам и выходит с кодом 1, если p90 шага
   выше порога.

## Отчёт

Заполняется после живого прогона на стенде (см. STEPS, A-3): таблица по узлам,
p90 шага против порога 60 с, выводы.
