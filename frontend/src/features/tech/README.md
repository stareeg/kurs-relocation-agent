# Технички (`tech`)

домен бэкенда: `core/domains/preparation`

Подготовка к техсобесам, этапы, разбор транскрипта. Helper-бывшие
`prep/` и `debrief/` живут здесь же.

## Композер — два режима, не три

`PrepChat` переключает «Агент» / «Расшифровка». Режима «Внешний ИИ» больше нет: вставленную чужую
переписку разбирает сам агент — он решает, продолжение это разговора или сторонние готовые пары
вопрос-ответ (блок «Владелец вставил чужую переписку» в промпте `answer_prep_chat`). Эндпоинт
`POST /api/prep/{id}/parse-external` остался для программных клиентов, веб им не пользуется.

У «Расшифровки» появляется галка (`ModeSegment done`), когда по этапу разбор уже есть.

## Разбор расшифровки

`DebriefSection` → `DebriefReview`: одна карточка на разбор — шапка с единственной оценкой
(`overall_impression` + сигнал + привязка к этапу + итог) и вкладки:

- **Диалог** — реплики транскрипта пузырями (`TranscriptChat`), раскрыты сразу, без спойлера;
- **Разбор** — один список «вопрос → как ответил → что доработать» (`debrief-review.ts`
  склеивает `questions_asked` / `question_mastery` / `weak_answers` / `honest_notes`), плюс
  «Что зашло» из `strong_answers`.

Прошлые разборы — та же карточка, но `collapsible`. Оценка на экране ровно одна: раньше её
показывали и закреплённый пузырь-итог, и шапка каждой старой карточки.

Разбор — фоновая задача (`useAnalyzeDebrief`): поле очищается сразу после «Анализ», композер
уходит в «Агент», прогресс идёт карточкой `DebriefProgress` (черновая разметка реплик
`draftTranscriptTurns` + шаги статуса). Упавшая задача держит текст у себя — «Повторить» и
«Вернуть текст в поле» работают из той же карточки.

После разбора этапа prep-артефакты прячутся (`hasRealDebriefForStage`): мок-вопросы, «Бриф
подготовки» и «Опорный каркас» описывают уже прошедший собес прогнозом.
