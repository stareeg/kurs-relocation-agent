# Аккаунт (`settings`, маршрут `/settings`)

Пользовательское имя раздела — **«Аккаунт»** (не «Параметры»). Вход из футера профиля
сайдбара; отдельного пункта в меню нет.

Домен бэкенда настроек/токена: `core/domains/profile`. Дружба — API `career`, UI здесь.

- Вход: `AuthTokenSection` — токен из официального бота (ссылка всегда видна, автовход при
  вставке); кнопка «Выйти» в свёрнутом блоке входа (не в сайдбаре). При выдаче токена бот
  сразу пишет `telegram_owner` — отдельной «Привязать» в UI нет.
- Ключ OpenRouter: `SettingsForm` — при отсутствии ключа поле вставки; после принятия —
  свёртка с галочкой и статистика токенов (`UsageStats`): «Сегодня» / «За месяц» (30 дней) по
  столбцам, «Базовые» / «Продвинутые» по строкам — источник `GET /api/metrics` → `token_stats`.
- Устройства: активные сессии входа.
- Друзья: `FriendsCompactSection` (код дружбы + список) — лобби мультиплеера цепляется к этому.
- Prefs пушей (дайджест / прогрев / стиль / уборка) зашиты дефолтами на бэкенде
  (`telegram_prefs`) — селектов в UI нет.
- Контекстная помощь — панель «Что делать?» в сайдбаре; глобального тумблера «Подсказки» нет.
- Логи обычным пользователям отдельной кнопкой в разделе не отдаём: бандл — тост при ошибке /
  `ErrorBoundary`, оператор смотрит из админки.
- Веса скоринга **не** правятся здесь и не правятся в «Резюме» отдельной формой — рубрика из
  резюме; `scoring_weights` в API — read-only display plumbing для разбора балла.
