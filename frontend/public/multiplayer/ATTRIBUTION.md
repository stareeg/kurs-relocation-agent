# Ассеты «Мультиплеер»

Лёгкие SVG под кабинет найма. Сырьё внешних паков — локально в `gfx/raw/` (gitignore);
в прод уходят только оптимизированные файлы из этой папки.

| Файл | Назначение | Лицензия |
| --- | --- | --- |
| `paper-grain.svg` | зерно бумаги (pattern, CSS background) | собственный |
| `felt-noise.svg` | шум сукна (CSS background) | собственный |

Рубашка карты, головка штампа и молния энергии рисуются инлайн-SVG прямо в компонентах
(`CardFace`, `StampButton`, `EnergyPips`) — внешние файлы `card-back.svg` / `stamp-head.svg` /
`icon-bolt.svg` убраны: `<img src>` был единственным звеном, отваливавшимся «крашнутой
картинкой» (у `stamp-head.svg` вдобавок были управляющие символы в тексте — битый XML).
