# app

Сценарии между доменами, примитив Pipeline и композиционный корень.

Роутеры и бот зовут отсюда кросс-доменные use-case'ы; домены `app` не импортируют.

- `wiring.py` — единственное место, где домен и инфраструктура встречаются:
  реализации портов `kernel/ports.py` поверх `core.platform` (`PlatformLlm`, `PlatformCache`).
  `wire_default_ports()` зовут `api.main` (lifespan) и `bot_app.run`; для CLI/скриптов есть
  ленивая страховка в `kernel.ports` (импорт корня по строке — статической зависимости
  `kernel → app` нет).
- Pipeline — именованные шаги с параллелизмом и частичной деградацией.
